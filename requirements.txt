# Step 1 of 2.  Install with:
#     pip install -r requirements.txt
#
# Then step 2 (REQUIRED - see note below):
#     pip install --no-deps face_recognition face_recognition_models
#
# Why two steps: the `face_recognition` package declares a hard dependency on
# `dlib`, which is published only as a source archive and needs CMake plus a
# C++ toolchain to build. `dlib-bin` below is the same library shipped as a
# prebuilt wheel, but pip does not treat it as satisfying the `dlib`
# requirement. Installing face_recognition with --no-deps therefore keeps the
# prebuilt wheel and avoids a source build. Every dependency it actually needs
# at runtime is already pinned in this file.
# ---------------------------------------------------------------------------
